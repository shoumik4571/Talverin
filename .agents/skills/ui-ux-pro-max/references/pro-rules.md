# Common Rules for Professional UI + Pre-Delivery Checklist

## Pre-Delivery Checklist (UI/UX Pro Max)
- [x] No emojis as structural icons (use SVG Lucide icons only)
- [x] Progressive Disclosure: One focused question per onboarding screen (never overwhelm upfront)
- [x] `cursor-pointer` on all clickable elements
- [x] High-contrast text (minimum 4.5:1 contrast ratio; never white text on white background)
- [x] Context-aware Framer Motion spring transitions & Skiper UI micro-interactions
- [x] Keyboard Enter / Back navigation on every question screen
